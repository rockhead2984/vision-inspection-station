# 웹캠 기반 미니 비전 검사 스테이션 (OpenCV + YOLO)

반도체 검사장비가 "영상 획득 → 전처리 → 판별·측정 → 판정 → 기록" 순서로 동작하는 흐름을 축소해서 직접 구현해본 학습 프로젝트입니다.

- **YOLO**: 무슨 물체인지 판별 (딥러닝, 사전학습 모델)
- **OpenCV**: 물체 길이 측정 (규칙 기반 영상처리)
- **판정 로직**: 등록 여부·크기 범위로 PASS / FAIL, 검사 이력 CSV 기록

## 실행

```
pip install -r requirements.txt
python station.py      # SPACE: 검사 확정·기록, Q: 종료
```
`yolov8n.pt`는 첫 실행 때 자동으로 다운로드됩니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `cam_test.py` | 웹캠 영상 출력 |
| `opencv_basic.py` | 흑백 → 블러 → Canny 엣지 → 윤곽선 → 박스·개수 표시 |
| `opencv_tune.py` | 트랙바로 Canny 임계값·최소 면적을 바꿔가며 결과 비교 |
| `yolo_test.py` | YOLOv8n 사전학습 모델로 물체 검출 |
| `inspection.py` | YOLO 입력 해상도별 처리 시간 측정 (`r` 키로 전환) |
| `station.py` | 검사 스테이션: ROI → YOLO 판별 → OpenCV 길이 측정 → 판정 → CSV 기록 |
| `inspection_log.csv` | 검사 기록 예시 |

## 검사 흐름 (`station.py`)

```
웹캠 프레임
 → ROI: 화면 가운데 절반만 검사 영역으로 자르기
 → YOLO(imgsz=480): 물체 종류 판별, 신뢰도 0.5 미만 무시
 → OpenCV: 흑백 → 블러 → Otsu 이진화 → 가장 큰 윤곽선 → minAreaRect로 긴 변 길이(px)
 → 판정: 미등록 물체면 FAIL(unregistered), 길이가 범위 밖이면 FAIL(size), 아니면 PASS
 → SPACE: CSV 기록, 총 검사 수·불량률 표시
```

## 성능 측정: YOLO 입력 해상도

| imgsz | 처리 시간 | FPS (모델 처리만) | 검출 |
|---|---|---|---|
| 640 | 31 ms | 31 | 잘 잡힘 (기준) |
| **480** | **23 ms** | **40** | 잘 잡힘 → **선택** |
| 320 | 14 ms | 70 | 작은 물체를 놓치기 시작 |
| 160 | 8 ms | 120 | 못 잡음 |

640 대비 처리 시간을 약 26% 줄이면서 검출 결과는 유지되는 480을 최적값으로 선택했습니다. FPS는 모델 처리 시간만 기준이라, 실제 화면은 웹캠 프레임레이트에 묶입니다.

## 검사 결과와 관찰

| 물체 | YOLO 인식 | 길이 | 결과 |
|---|---|---|---|
| 마우스 | mouse (0.90~0.91) | 154 / 156 px | PASS, 반복 측정 차이 2px |
| 핸드폰 | cell phone (0.60~0.86) | 196 px(10/28) / 272 px(11/05) | PASS |
| 유리컵 | vase (꽃병으로 오인식) | 199 px | FAIL (미등록) |
| 사람 | person | 266~268 px | FAIL (미등록) |

1. **카메라 높이가 바뀌면 같은 물체도 픽셀 길이가 달라진다.** 날짜마다 카메라 위치가 달라 핸드폰이 196px → 272px로 측정됐습니다. 실제 장비처럼 카메라를 고정하고, 픽셀을 mm로 바꾸는 캘리브레이션이 필요합니다.
2. **사전학습 모델의 한계.** 투명한 유리컵을 "vase"로 오인식했습니다. 원하는 대상을 정확히 판별하려면 직접 수집한 데이터로 다시 학습해야 합니다.
3. **규칙 기반 처리의 한계.** 윤곽선 방식은 조명·배경에 민감해서 얼굴처럼 경계가 흐린 대상은 박스가 끊겼습니다. 그래서 판별은 YOLO, 측정은 OpenCV로 역할을 나눴습니다.

## 한계와 다음 단계

- YOLO는 직접 학습시키지 않았습니다 (COCO 사전학습 모델 사용)
- 길이는 픽셀 단위이며, 카메라 보정(mm 변환)은 하지 않았습니다
- 판정은 물체 종류·크기만 보며, 표면 결함(스크래치 등) 검출은 아닙니다
- 다음 단계: 카메라 고정 + 기준 물체로 px→mm 변환, 직접 촬영한 데이터로 YOLO 재학습, 라즈베리파이 카메라로 이식
